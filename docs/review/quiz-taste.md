**필수 여부:** 필수

- 만드는 편 — 직접 뭔가를 하는 편이다

### 2. [experience] tasteRecent

**질문:** 최근 일주일, 실제로 시간을 가장 많이 쓴 건?

- 책·글 읽기 — 종이든 화면이든

### 3. [binary] tasteDepth

**필수 여부:** 필수

**선택지:**
- 끝까지 파는 편 — 하나를 깊게 파고드는 편이다
- 여러 개를 얕게 즐기는 편 — 넓게 훑는 편이다

### 4. [quickTap] tasteDiscover

**질문:** 새로운 걸 알게 되는 경로는 주로 어디야?

**필수 여부:** 필수

- 사람 추천 — 친구나 아는 사람이 알려주는 편이다
- 직접 찾아보는 편 — 검색하고 뒤져보는 편이다
- 우연히 마주치는 편 — 딱히 찾지 않아도 걸리는 편이다

### 5. [quickTap] tasteMoney

**필수 여부:** 필수

- 먹는 데 — 맛있는 거 사 먹는 데 썼다
- 경험에 — 공연·전시·여행 같은 데 썼다
- 물건에 — 사고 싶던 걸 샀다
- 안 쓰고 남겼다 — 모아두는 편이다

- 이야기가 잘 짜인 것 — 구성이 중요한 편이다
- 분위기와 미장센 — 느낌이 중요한 편이다
- 남기는 메시지 — 생각할 거리가 중요한 편이다

### 8. [preference] tasteSpace

### 9. [quickTap] tasteFood

**필수 여부:** 필수

- 그때 기분 따라 정하는 편 — 즉흥적인 편이다

- 화려한 — 채워진 것
- 빈티지한 — 오래된 것
- 자연스러운 — 꾸미지 않은 것
- 정갈한 — 반듯한 것
- 개성 강한 — 튀는 것

### 11. [preference] lifestyle

**질문:** 평소 생활에서, 나와 더 가까운 모습은?

**필수 여부:** 필수

**선택지:**
- 집순이·집돌이 — 집에서 보내는 시간이 제일 편하다
- 액티브·야외파 — 밖에서 몸을 움직이는 걸 좋아한다
- 취미 공유 — 좋아하는 걸 남과 같이 하려는 편이다
- 각자 시간 존중 — 따로 보내는 시간도 자연스럽다
- 여행 좋아하는 — 떠나는 것 자체를 즐긴다
- 규칙적인 생활 — 일상의 리듬이 안정적인 편이다

### 12. [quickTap] tasteShare

**질문:** 좋아하는 걸 남한테 얘기하는 편이야?

**필수 여부:** 필수

**선택지:**
- 자주 추천하는 편 — 알리고 싶은 편이다
- 물어보면 말하는 편 — 먼저 꺼내진 않는 편이다
- 혼자 간직하는 편 — 내 것으로 두고 싶은 편이다
- 알려지면 오히려 식는 편 — 많이 알려지면 흥미가 떨어지는 편이다

### 13. [binary] tastePopular

**질문:** 남들이 다 좋아하는 것, 나는 어느 쪽이었어?

**필수 여부:** 필수

**선택지:**
- 나도 좋으면 같이 좋아한 편 — 유행을 따라간 편이다
- 오히려 거리를 둔 편 — 몰리면 빠지는 편이다

### 14. [quickTap] tasteRepeat

**질문:** 좋아하는 걸 다시 볼 때 나는 어떤 편이야?

**필수 여부:** 필수

**선택지:**
- 여러 번 반복하는 편 — 같은 걸 계속 보는 편이다
- 한 번이면 충분한 편 — 다시 안 보는 편이다
- 시간이 지나 다시 찾는 편 — 한참 뒤에 돌아오는 편이다
- 애초에 끝까지 안 보는 편 — 중간에 그만두는 편이다

### 15. [experience] tasteGuilty

**질문:** 남들에게 말하긴 좀 그런데 실제로 좋아하는 게 있어?

**필수 여부:** 필수

**선택지:**
- 있다, 대놓고 즐긴다 — 숨기지 않는 편이다
- 있지만 티는 안 낸다 — 혼자만 즐기는 편이다
- 딱히 없다 — 숨길 만한 게 없는 편이다
- 예전엔 있었는데 이젠 아니다 — 지금은 신경 안 쓰는 편이다

### 16. [quickTap] tasteChange

**질문:** 예전과 비교하면 내 취향은?

**필수 여부:** 필수

**선택지:**
- 거의 그대로인 편 — 오래 좋아한 게 계속 간다
- 조금씩 넓어진 편 — 예전 것에 더해지는 편이다
- 완전히 바뀐 편 — 예전에 좋아하던 게 지금은 아니다
- 계속 바뀌는 편 — 한 곳에 오래 머물지 않는 편이다

### 18. [preference] tasteWhy

**질문:** 나한테 취향은 어떤 의미야?

**필수 여부:** 필수

**선택지:**
- 나를 설명하는 것 — 내가 어떤 사람인지 보여준다
- 쉬는 방법 — 숨 돌리는 시간이다
- 사람과 이어지는 통로 — 같이 좋아할 사람을 만난다
- 계속 배우는 것 — 알수록 재밌어진다
- 그냥 습관 — 딱히 의미는 없다
- 스트레스를 푸는 법 — 버티게 해주는 것이다

### 19. [quickTap] tasteIdeal

**질문:** 취향이 잘 맞는 사람과 만나면 어때?

**필수 여부:** 필수

**선택지:**
- 제일 편하다 — 말이 통해서 좋다
- 좋긴 한데 필수는 아니다 — 다른 게 더 중요하다
- 오히려 다른 게 재밌다 — 새로운 걸 알게 돼서 좋다
- 취향 얘기를 잘 안 한다 — 그런 대화를 잘 안 하는 편이다

### 20. [binary] tasteSelfView

**질문:** 나는 취향이 뚜렷한 사람인 것 같아?

**필수 여부:** 필수

**선택지:**
- 그런 편인 것 같다 — 좋아하는 게 분명하다고 느낀다
- 잘 모르겠다 — 딱히 뚜렷하지 않다고 느낀다
